# art

Art games, published at https://games.hoai.net/art/.

- **[The Ice-Cream Cone Coot](https://games.hoai.net/art/icecreamcone/)** · [`icecreamcone/`](icecreamcone/README.md): a field guide of rare birds from Arnold Lobel's book, with a minigame for each
- **[Bronze Drum](https://games.hoai.net/art/bronzedrum/)** · [`bronzedrum/`](bronzedrum/README.md)
- **[Kingdom of the Fairies](https://games.hoai.net/art/kingdomofthefairies/)** · [`kingdomofthefairies/`](kingdomofthefairies/README.md)
- **[Fibre Art](https://games.hoai.net/art/fibreart/)** · [`fibreart/`](fibreart/README.md): a shifting collage after the fibre art, paintings and drawings of Hanneke de Neve

Which games are deployed is `deploy_config.json`; how deploys work is in `CLAUDE.md`.
